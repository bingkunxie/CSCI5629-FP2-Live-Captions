# 离线 Emoji 与会议纲要

## 戴上 Quest 后怎么用

1. 打开 **FP2 Live Captions**。
2. **按下右摇杆**展开/收起表情菜单；也可用右手柄瞄准“表情 +”，按食指扳机。
3. 选择点赞、鼓掌、爱心或疑问。两人模式下，对方收到弹窗，约 **2.5 秒**后消失。单机模式显示“本机预览”。
4. 放下手柄、启用 Quest 手部追踪后，做清晰的竖大拇指动作即可快捷发送点赞。每次先松开手势再重复；菜单内可以关闭快捷发送。
5. **按下左摇杆**进入纲要编辑器。会前填写要点、保存；会中纲要持续显示在字幕旁。
6. 用右手柄瞄准纲要中的一行，按食指扳机即可勾选或取消完成。最多 **6 项，每项 60 字符**；部分特殊字符占两个字符位置。
7. 头显内有离线英文键盘。中文可通过“Keyboard / 中文”请求系统输入法（取决于设备支持），也可以用电脑编辑页输入。

操作表情菜单或纲要编辑器时，扳机不会开始录音。右握把仍打开原有的对话记事本/工具菜单。

## 两台头显共享

两台 Quest 配置为 A、B，连接同一台电脑的本地中继。无需校园网、API 或互联网，但必须能访问中继所在的局域网地址。具体配置见 [双人会话说明](Two-Quest-Session.md)。

中继启动后，在电脑打开 http://127.0.0.1:8767 即可输入中文纲要，每行一个要点。点击“保存并同步”，内容会发送到已连接的头显。任一头显或电脑勾选，其他端都会更新。

纲要保存在本地，重启仍保留。两人同时修改文本产生冲突时，系统提示重新载入；不会静默覆盖。断线期间保留显示已缓存纲要，但不宣称编辑已同步。表情不写入对话记事本，也不会在重连后重放。

## 单台头显离线使用

无需运行中继，就能编辑、保存和勾选本机纲要，并预览表情。电脑编辑页还支持导出纲要，通过 USB 导入单机头显，见 [导入命令](Meeting-Tools.md#standalone-agenda-import)。

## 验证范围

自动测试覆盖纲要保存/恢复、并发勾选、编辑冲突、表情去重和时效，以及菜单避免误触录音。两台真实头显的无线联机与实际手势体验仍需现场验收。校园网语音识别、翻译和朗读测试按要求暂缓；本次两个新功能均不依赖这些服务。
