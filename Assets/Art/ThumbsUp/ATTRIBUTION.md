# Thumbs-up effect artwork

The gold hand, blue cuff, and sparkles are original geometric artwork authored for this project in `ThumbsUpEffectsSetup.BuildIcon`. They use Unity UI rectangles and the standard UI material. No third-party image, emoji font, generated bitmap, or custom shader is included.

Native pose detection uses the installed Meta Interaction SDK's `FingersAllClosed`, `ThumbUp`, and default transform thresholds. Those SDK assets remain in their original package and are governed by the Oculus SDK License Agreement distributed with that package.
